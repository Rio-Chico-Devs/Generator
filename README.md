# Vihente Forge

App desktop offline che apprende il tuo stile artistico e lo replica
in nuove immagini. Nessun cloud, nessuna telemetria, nessun account.
I tuoi lavori restano sul tuo computer.

## Cosa fa

- Crea **progetti** indipendenti per ciascuno dei tuoi stili
  (sprite gothic, background neumorphic, illustrazioni, loghi…)
- Apprende dal materiale che fornisci (50-200+ immagini per stile)
- Genera nuove immagini coerenti con lo stile appreso
- Variazioni da immagine esistente (img2img)
- Inpainting, outpainting, upscale
- Modalità "Forge": bozza sketch a matita → l'app dipinge nel tuo stile

## Requisiti minimi

- GPU NVIDIA con 8+ GB VRAM (RTX 2070+, 3060+, 4060+…)
- 16 GB RAM
- 50 GB disco
- Windows 10/11, Linux Ubuntu 22+
